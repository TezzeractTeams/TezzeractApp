# App Platform

The app store / micro-app tier — attendance checkers, room booking, and future small
tools, each installable per organization the same way Contelli or Talk are.

**Status:** SDK and scaffold not yet built. Planned for Phase 2 of the
[Revenue-First Plan](../architecture/technical/40-revenue-first-plan.md), once the Kernel
exists for a micro-app to inherit tenancy and agent integration from.
