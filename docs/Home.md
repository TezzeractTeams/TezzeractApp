## Using this vault

- **Mermaid** diagrams render natively.
- **Heading links** such as `10-decisions.md#adr-019` open the right file but won't jump to
  the section, because Obsidian anchors on heading text rather than the slugs the docs site
  uses.
- **Links that leave the vault** (`../../SUPABASE_SETUP_GUIDE.md` and similar repo-root
  files) show as unresolved. They point at code-repo files, not notes.
- **`_sidebar.md` files** are hidden. They only feed the docs-site navigation.
