# Contelli

Social media and content intelligence — the module you can also buy standalone at
[contelli.co](https://contelli.co), independent of the rest of Tezzeract.

**Status:** working today — real OAuth (Google/Meta/Twitter), scheduled publishing,
dashboards. Built under the internal name `social`; the rename to `contelli` and an
explicit build-vs-park decision are both still outstanding — see
[Current State](../architecture/06-current-state.md).
